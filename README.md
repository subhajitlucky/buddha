# Buddha - A World-Class Website Dedicated to the Enlightened One

A comprehensive, authentic, and visually stunning website dedicated to the life and teachings of Buddha, built with React and Vite.

## About

This project aims to create a world-class digital sanctuary that honors the life and teachings of Siddhartha Gautama, the Buddha. Our website provides an authentic resource for learning about Buddhism, featuring:

- The complete life story of Buddha from birth to enlightenment, sourced from the earliest texts
- Core teachings including the Four Noble Truths and Noble Eightfold Path with references to specific suttas
- Comprehensive meditation practices with guidance from the Satipatthana Sutta and other texts
- Detailed information about Buddhist texts and scriptures with historical context
- All content carefully sourced from authentic ancient texts and scholarly research

## Features

- Responsive design that works on all devices
- Interactive timeline of Buddha's life with source references
- Comprehensive teachings section with key discourses and concepts
- Detailed meditation guides with authentic practices
- Extensive Buddhist texts section with preservation history
- Beautiful, contemplative design inspired by ancient Buddhist art
- Source citations for all information presented
- Fast loading times with Vite optimization

## Tech Stack

- **Frontend**: React 18 with Hooks
- **Build Tool**: Vite
- **Styling**: CSS Modules
- **Deployment**: Vercel
- **Routing**: React Router

## Development

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```

## Content Authenticity

All content on this website is carefully sourced from authentic ancient texts and scholarly research:

- **Primary Sources**: Pali Canon (Tipitaka), the earliest complete collection of Buddhist texts
- **Additional Sources**: Sanskrit texts, Chinese translations, and academic research
- **Historical Context**: Archaeological findings and historical research on 6th century BCE India
- **Clear Distinctions**: Between earliest teachings likely from the historical Buddha and later developments

We distinguish between the earliest teachings (found in the core Nikayas/Agamas) and later developments in Buddhist thought, clearly indicating sources for all information presented.
