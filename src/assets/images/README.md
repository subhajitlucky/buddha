# Authentic Images for the Buddha Website

This directory is reserved for authentic images from the Buddha's time period or early Buddhist art.

## Guidelines for Authentic Images:

1. **Historical Accuracy**: Only images from the 6th century BCE to 1st century CE that depict Buddhist themes or are archaeologically verified.

2. **Archaeological Sources**: 
   - Sculptures from Bharhut (2nd century BCE)
   - Sanchi Stupa reliefs (2nd century BCE - 1st century CE)
   - Amaravati sculptures (1st century BCE - 3rd century CE)
   - Gandhara art (1st century BCE - 5th century CE)

3. **Artistic Representations**:
   - Early aniconic representations of the Buddha (footprints, throne, Bodhi tree)
   - Mathura school sculptures
   - Cave paintings from Ajanta (2nd century BCE - 6th century CE)

4. **Manuscript Illustrations**:
   - Dunhuang manuscripts
   - Palm-leaf manuscript illustrations

## Current Status:

No images have been added yet. When authentic images are sourced, they should be placed in this directory with proper attribution and historical context.

## Note on Image Usage:

Any images added must:
- Be in the public domain or used with proper permission
- Include detailed source information
- Have historical verification of authenticity
- Be appropriate for educational use
